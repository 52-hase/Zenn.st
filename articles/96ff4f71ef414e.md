GitHub Actions(CI)
RuboCop(静的解析)、RSpec(テスト)

フロントエンド
JavaScript
Bootstrap

バックエンド
Ruby 3.2.2
Ruby on Rails 7.1.3
Node.js
WebSocket(ActionCable)によるリアルタイムチャット

データベース
PostgreSQL

インフラ
Heroku
AWS S3(画像の保存)
